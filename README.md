# Carry On

A desktop packing-list web app that saves its list in browser storage. Items can be added, renamed, deleted, packed, unpacked, and filtered to show what is left.

## Development

```sh
npm install
npm run dev
```

## Checks

```sh
npm test
npm run build
```

The production build is written to `dist/`. The app is client-only and has no server or account-backed storage.
