## Why

People need a quick way to learn how many lines a text file has. A small command-line tool can give a clear count without the need to check the file by hand.

## What Changes

- Add a command-line tool that accepts a text file.
- Report the number of lines in that file.
- Report zero when the file is empty.

## Capabilities

### New Capabilities

- `text-line-count`: Covers how the tool counts and reports lines in a text file.

### Modified Capabilities

None.

## Impact

The project will gain a small command-line tool. It will read a text file and write its line count to standard output.
