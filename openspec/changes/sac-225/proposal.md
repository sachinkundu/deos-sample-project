## Why

People need a quick way to do basic math in a web page. This small tool also gives the team a clear test of the full delivery flow from plan to live preview.

## What Changes

- Add a web calculator for addition, subtraction, multiplication, and division.
- Let people enter whole numbers and decimals with on-screen buttons or a keyboard, then show the result.
- Add a clear action that resets the calculator. Show a clear error for division by zero and let the person clear it and start again.
- Make the page fit and stay easy to use on phone and desktop screens.
- Share a working preview for final review. Give visual proof of button use, key use, clear recovery, and division by zero. Add automated tests for each math action. Test decimals, buttons, keys, clear, and recovery from division by zero.

## Capabilities

### New Capabilities

- `web-calculator`: Do basic math in a web page that fits phone and desktop screens, with two input modes, clear recovery, and review proof.

### Modified Capabilities

None.

## Impact

This adds a web page, its calculator behavior, tests, a live preview, and visual review proof. It does not change an existing API or stored data.
