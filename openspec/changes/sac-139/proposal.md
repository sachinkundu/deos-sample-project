## Why

People need a quick way to do math in a terminal. They also need to change heat values. Clear commands and errors will make the tool easy to use.

## What Changes

- Add four basic math commands.
- Add ways to change values between Celsius, Fahrenheit, and Kelvin.
- Set clear rules for input, output, and errors.

## Capabilities

### New Capabilities

- `calculator-cli`: Covers math, heat unit changes, results, and errors for the terminal tool.

### Modified Capabilities

None.

## Impact

The project will gain a small terminal tool. It will read values and action names from its input. It will send results to standard output. It will send errors to standard error.
