## Purpose

This guide helps people make clear and safe reports about sample app problems.

## ADDED Requirements

### Requirement: Ask for the problem details

The guide MUST ask what happened. It MUST ask what the reader expected. It MUST ask how to repeat the problem.

#### Scenario: Read the report guide

- **WHEN** a person reads the guide
- **THEN** it asks what happened, what they expected, and how to repeat the problem

### Requirement: Keep private data out of reports

The guide MUST say not to put passwords or private data in a report.

#### Scenario: Check the report safety note

- **WHEN** a person reads the guide
- **THEN** it says not to put passwords or private data in a report
